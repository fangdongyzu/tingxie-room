# 聽寫室（GitHub Pages 版）

這是一個完全靜態的中文聽寫網站。老師現場播放音訊或朗讀，學生親手輸入，完成後截圖交卷。

## 功能

- 不需要伺服器、資料庫或學生帳號
- 阻止貼上、拖放、複製與常見快捷鍵
- 畫面顯示學生姓名、裝置代碼與即時浮水印
- 記錄離開畫面、貼上嘗試與可疑的大段文字插入
- 完成後產生適合截圖的交卷畫面
- 老師可在首頁產生包含測驗名稱和班級的學生專用連結

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的公開 repository，例如 `tingxie-room`。
2. 把這個資料夾的檔案推送到 repository 的 `main` branch。
3. 在 repository 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/(root)`，然後按 **Save**。
6. 等待數分鐘後，GitHub 會顯示網站網址，通常是：

   `https://你的GitHub名稱.github.io/tingxie-room/`

## 上課使用

1. 老師開啟網站，移到下方的「老師建立專用連結」。
2. 輸入聽寫名稱和班級，按「產生學生連結」。
3. 把連結傳給學生。
4. 學生輸入姓名，開始聽寫。
5. 完成後按「完成聽寫」和「準備截圖」。
6. 學生把完整截圖傳給老師。

## 限制

純靜態網站不能真正辨識硬體、阻止系統截圖，或把作答資料傳回老師。裝置代碼是保存在瀏覽器中的隨機識別碼，學生清除瀏覽器資料後會改變。姓名浮水印和操作紀錄主要用於提醒與嚇阻，不能作為絕對的防作弊證明。
